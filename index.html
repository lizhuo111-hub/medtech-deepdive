关键洞察 Key Takeaways

2026 一季报综合分析
① 集采影响两极分化:龙头赢家通吃,二三线继续承压
2026Q1 大博医疗 +42.16% / 联影 +7.78% / 迈瑞 -11.37% (但营收已转正),新产业 +1.02% 增长放缓;而乐普 -34.80% / 安图 -12.39% / 欧普康视 -8.79% 继续承压。赛道头部公司通过份额扩大抵消价格压力,二三线则被集采 + DRG + 渠道库存三重重压。
② 出海 + 设备更新 = 2026 增长双引擎
联影 2026Q1 海外 +33.81% (2024)→ 2025 进一步 51.39% 增长;迈瑞国际 2026Q1 营收 44.49 亿 +15.70%;新产业海外 +19.16% (2025);大博 +10% 海外占比。设备更新政策+海外市场,共同推动 2026Q1 拐点。
③ 港股两巨头命运不同:威高承压 / 微创扭亏
微创医疗 2024 净亏 2.68 亿美元 → 2025 全年扭亏为盈 4850 万美元,通过处置微创机器人、脑科学、骨科资产回笼 3 亿美元;心脉医疗 2026Q1 营收 3.7 亿 +11.45% / 净利 1.55 亿 +19.44% 持续高增。威高股份 2025 全年净利 -22.0%,2026 需观察骨科业务恢复节奏。
④ OK 镜赛道竞争白热化:双龙头双承压
欧普康视 2026Q1 营收 -3.92% / 净利 -8.79%,核心硬镜毛利率下滑,募投项目延期 3 年;爱博医疗 2026Q1 增收 +11.50% / 净利 -3.55%,商誉增加 + 应收账款上升。低浓度阿托品、软性减离焦镜分流 OK 镜市场,行业进入存量博弈。
