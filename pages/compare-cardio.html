3 种心血管介入发展路径

① 惠泰医疗

688617.SH
路径:小而美 · 迈瑞入主 · 电生理+冠脉双龙头
  • 2025 营收:25.84 亿 / +25.08%
  • 2025 净利:8.21 亿 / +21.91%
  • 净利率:31.26%(行业第一)
  • 毛利率:72.88%
  • 海外占比:13.03%
  • 核心赛道:电生理(国产第一)+ 冠脉通路(国产第一)
  • 重磅产品:PFA 国产首批获批(2024-12)
  • 迈瑞入主:2024-01, 24.61% 股权,66.5 亿
  • 2026Q1:营收 7.04 亿 +24.78% / 净利 2.29 亿 +25.27%

② 乐普医疗

300003.SZ
路径:多元化平台 · 集采承压 · 结构性心脏病高增
  • 2025 营收:64.83 亿 / +6.22%
  • 2025 净利:9.62 亿 / +289.57%(低基数恢复)
  • 净利率:14.8%
  • 毛利率:~64%
  • 业务:医疗器械 + 药品 + 医疗服务三大板块
  • 核心赛道:冠脉植介入 + 结构性心脏病 + 药品(零售)+ IVD
  • 亮点:结构性心脏病 +44% / 创新药 MWN101/MWN105 推进
  • 2026Q1:营收 16.7 亿 -3.7% / 净利 -34.8%
  • 挑战:2024 净利仅 2.47 亿(创上市以来最低)

③ 微创医疗

0853.HK
路径:港股多元化集团 · 资产处置扭亏 · 创新业务孵化
  • 2025 营收:11.05 亿美元 / +6%(约 78 亿 RMB)
  • 2025 净利:4851.9 万美元 / 扭亏(vs 2024 亏 2.68 亿)
  • 净利率:~4.4%
  • 毛利率:57.4%
  • 海外占比:70%(出海贡献同比 +70%)
  • 业务:心血管 + 骨科 + 心律管理 + 大动脉 + 神经介入 + 心脏瓣膜 + 手术机器人
  • 亮点:手术机器人 +286.6% / 结构性心脏病 +255%(海外)
  • 2025 公告:累计 44 款产品入国家创新医疗器械"绿色通道"
  • 挑战:持续亏损到 2024,2025 靠资产处置+降本扭亏

惠泰:净利率 31.26% 行业第一(远超高耗同业 15-20% 平均水平),毛利率 72.88% 创历史新高,经营现金流 6.86 元/股,资产负债率仅 12% 极致稳健。2025 净利 8.21 亿 = 乐普 9.62 亿的 85% 水平,但营收只有乐普的 40% → 单位收入盈利能力是乐普的 2 倍多。

微创:港股不披露 Q1,2025 营收 78 亿 RMB 规模超过乐普,但净利仅 3.4 亿(净利率 4.4%),靠资产处置+降本扭亏。海外占比 70% 是 3 家中最高,出海能力最强。

惠泰 · 国际化布局

  • 海外占比: 13.03% (3.37 亿)
  • 增速: +20.25%
  • 自主品牌: +30%+ (亚太/拉美/西欧 +35%+)

乐普 · 国际化布局

  • 海外占比: ~20% (估)

  • 重点市场: 东南亚 / 印度 / 中东 / 南美

9. 战略路径对比

3 种不同的发展哲学
惠泰 · "专精 + 借力"
  • 聚焦心血管介入(电生理 + 冠脉 + 外周)
  • 2024 引入迈瑞(产业资本)
  • 借迈瑞渠道 + 供应链赋能
  • 借迈瑞资金加大研发 + 海外
  • PFA 国产首批 → 房颤新蓝海
  • 关键词:小而美 + 强协同
乐普 · "平台 + 转型"
  • 心血管全产业链(器械 + 药品 + 服务)
  • 从仿制 → 创新(可降解支架 NeoVas)
  • 从器械 → 创新药(MWN101/105)
  • 从国内 → 海外 + 创新药许可出海
  • 集采承压 → 商誉减值出清
  • 关键词:大而全 + 转型中
微创 · "集团 + 创新"
  • 10+ 子业务覆盖全医疗器械
  • 心血管 + 骨科 + 心律 + 神经 + 机器人
  • 持续高研发(15% 营收占比)
  • 海外占比 70% 国际化最深
  • 多个子公司分拆上市
  • 关键词:集团化 + 全球化

📌 综合判断

3 种投资逻辑,3 个不同风险收益特征:

① 惠泰(688617) · 优选 — 国产电生理 + 冠脉通路双龙头,迈瑞入主后开启"专精 + 赋能"双轨模式。净利率 31.26% 行业第一,PFA 国产首批打开房颤千亿市场,2025-2026 持续高增。适合追求盈利质量 + 长期成长的投资者。

② 微创(0853.HK) · 港股折价机会 — 港股医疗器械集团化龙头,海外占比 70% 出海能力最强,创新业务(手术机器人 +286.6% 海外)+ 创新药(累计 44 款绿色通道)布局完整。2025 扭亏拐点确认,适合风险偏好高 + 看好出海 + 能接受港股折价的投资者。

③ 乐普(300003) · 谨慎 — 规模最大但增速最慢,2024 净利创历史新低,商誉 36 亿悬顶 + 应收账款 752% 异常。2025 反弹 +290% 主要来自商誉减值出清 + 药品零售清理的"出清反弹",2026Q1 净利 -34.8% 显示反弹持续性存疑。适合博弈反转 + 关注商誉减值出清节奏的投资者。
