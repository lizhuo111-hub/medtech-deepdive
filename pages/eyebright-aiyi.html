爱博医疗 688050.SH

投资视角综合分析

眼科耗材新锐 + 隐形眼镜国产化
✓ 核心优势
  • 三大业务协同:人工晶状体 + 角塑镜 + 隐形眼镜完整布局
  • 高增长持续:2018 以来每年净利均同比增长,2024 +27.36%
  • 隐形眼镜扭亏为盈:国产替代硅水凝胶(目前仅占国内 10%, 全球 70%)
  • 创新管线丰富:有晶体眼 / 焦深延长 / 散光矫正 / 硅水凝胶
  • ROE 提升:17.06%(+1.80pp),资产效率优化
  • 获批节奏快:2025 连续获批创新医疗器械
⚠ 风险点
  • 毛利率下降:集采 + 隐形眼镜毛利率低拖累
  • 利润增速慢于收入:隐形眼镜业务利润仍在爬坡
  • 股本扩张:80% 股本扩张摊薄 EPS 29.41%
  • OK 镜竞争:对标欧普康视,行业本身承压
  • 应收账款:
    —
  • 估值:PE-TTM 约 18-22 倍,处于历史中位
📌 综合判断
爱博医疗是国产眼科耗材"新三样"(晶体 + 角塑 + 隐形眼镜)的稀缺标的,2024 年高增长 + 隐形眼镜扭亏为盈是双拐点。隐形眼镜赛道国产化空间巨大(硅水凝胶在国内占比仅 10%, 全球 70%),公司持续投入研发,有望成为国产替代主力。短期受集采 + 隐形眼镜毛利率低影响,中期看隐形眼镜规模效应 + 创新晶体放量。适合作为"眼科 + 创新医疗器械"组合的成长配置。
