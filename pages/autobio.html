💡 v2.0 解读

化学发光竞争承压延续:2026Q1 营收 -0.37% 接近持平,净利 -12.39% 继续下滑,但降幅较 2025Q1 (-16.76%) 收窄。化学发光作为核心业务,2025 集采落地后单价下行,2026 仍处于"以价换量"消化期。微生物检测、临床检验自动化、流水线是公司差异化竞争力,但短期难以对冲化学发光价格压力。研发投入持续 +16.37% 体现长期战略,但短期 ROE 仅 14% 左右,需观察 H2 化学发光集采续标及安徽/江苏集采落地情况。

关键发展节点

Key Milestones
  • 1999-09: 郑州成立,聚焦免疫诊断试剂
  • 2016-09-01: 上交所主板上市

投资视角综合分析

国内承压 + 海外高速增长 + 研发持续
✓ 核心优势
  • 化学发光行业前三:免疫诊断 25.56 亿,毛利率 80.67%
  • 多产品线协同:免疫 + 微生物 + 生化 + 分子 + 仪器,5 大平台
  • 研发投入持续:7.32 亿(16.37% 费率),高素质研发团队
  • 新业务突破:分子诊断 +101%,思昆基因测序仪打开新空间
  • 海外加速:+36.57% 高速增长,国际展会频频亮相
  • 财务质量高:研发资本化率 0%,全部费用化
⚠ 风险点
  • 集采 + DRG 政策压力:国内业务 -1.16%
  • 扣非下滑大于收入:-7.30% vs +0.62%
  • 生化业务下滑:-11.21%
  • 海外占比仍小:8%,规模效应未充分体现
  • 2025Q1 继续承压:营收 -8.56% / 净利 -16.76%
📌 综合判断
安图生物是国产 IVD"产品线最全"的代表,免疫诊断行业前三,但短期面临集采 + DRG + 收费下调三重压力。研发持续高投入(16.37% 费率,全部费用化)保护了长期产品力,但压制短期利润。海外业务 +36.57% 是亮点,测序仪、质谱仪等新业务打开第二增长曲线。当前估值 PE-TTM 约 18 倍,处于历史中位偏低水平,适合作为"国产 IVD 困境反转 + 多产品线 + 海外突破"组合配置,关注 2025 H2 政策环境改善与海外持续放量。
