欧普康视 300595.SZ

中国 OK 镜(角膜塑形镜)绝对龙头,2000 年成立,2017 年创业板上市,总部安徽合肥。是国内首家也是规模最大的硬性角膜接触镜研发生产企业,旗下"梦戴维"品牌长期占据国内 OK 镜市场龙头地位。2024 年面临高端消费疲软 + 减离焦框架镜分流 + 竞品增加等多重压力,出现"增收不增利"局面。

增收不增利
⚠ 增收不增利主因
(1) 毛利率较高的 硬镜收入下降,毛利率较低的其它产品和医疗收入增加; (2) 销售费用 +22.40%(销售人员 + 技术支持人员 + 促销活动); (3) 新建视光终端前期投入大,收入小但固定成本高; (4) 计提长期股权投资减值 + 应收坏账 + 商誉减值合计 6,714 万(同比 +5,438 万)。 去除减值影响,净利下降约 7.52%。

💡 v2.0 解读

OK 镜竞争白热化,主业持续承压:2026Q1 营收 -3.92% / 净利 -8.79% / 扣非 -18.64%,三降齐现。核心产品硬镜(OK 镜)收入和毛利率双降,主要因:(1) 国产 OK 镜品牌增多 + 进口品牌价格战;(2) 低浓度阿托品、软性减离焦接触镜等替代品分流;(3) 高端消费疲软;重要信号 — 4月同步公告"社区化眼视光服务终端建设项目"从 2026-05 延期 3 年至 2029-05,投资额从 17.79 亿下调至 12.52 亿,新增 8.73 亿"股权收购投资"。从"自建终端"转向"并购整合",公司战略明显转向谨慎。2024/2025 净利已连续 2 年下滑 (-14.16% / -16.20%)。

投资视角综合分析

高毛利 OK 镜龙头 + 行业拐点
✓ 核心优势
  • OK 镜国产龙头:"梦戴维"长期占据国内最大份额
  • 高毛利 + 高现金流:硬镜毛利率 88.31%,经营现金流持续 > 净利
  • 研发储备丰富:巩膜镜 / 离焦软镜 / 滴眼液 / 双氧水护理液
  • 视光服务网络:470+ 自营终端 + 2,000+ 合作终端
  • 财务健康:资产负债率 14.71%,无有息负债
⚠ 风险点
  • OK 镜需求疲软:高端消费下行 + 出生率下降 + 减离焦框架镜分流
  • 竞品激增:爱博医疗、欧几里得等专业玩家增加,价格压力
  • Q4 加速恶化:营收 -8.38% / 净利 -61.38%
  • 销售费用刚性:+22.40%,新建终端投入大
  • 应收账款 + 减值:6,714 万减值,坏账风险
  • 视光终端盈利周期长:前期投入大,回报周期长
📌 综合判断
欧普康视是 OK 镜国产龙头,商业模式优秀(高毛利 + 重复消费 + 渠道粘性),但行业面临"消费降级 + 竞品 + 替代品"三重压力。2024 年增收不增利,2025 年仍需消化压力。公司应对策略清晰:巩膜镜 + 离焦软镜 + 阿托品滴眼液 + 视光中心 + 自研护理品,但需要时间兑现。当前估值 PE-TTM 约 25-30 倍,处于历史中位,适合作为"消费医疗 + 困境反转"组合配置,密切跟踪 2025 H2 业绩拐点与新品兑现。
