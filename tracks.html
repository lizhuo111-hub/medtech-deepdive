市场逻辑 / 投资逻辑 / 风险点

① 综合器械 — 迈瑞医疗 (300760.SZ)

市场逻辑: 中国医疗器械绝对龙头,产品对标 GE/Philips/Siemens。覆盖 IVD/监护/影像/微创外科四大领域,受国内医疗新基建 + 海外突破双重驱动。

投资逻辑: 发展中国家出海 +21% / 欧洲 +32% / AI 数智化(启元重症大模型) / 现金分红 65.15% / 累计分红 341 亿(IPO 募资近 6 倍)。

主要风险: 国内医疗专项债放缓 + 集采(IVD)+ 商誉 110.93 亿(占净资产 30.94%)。

② 高端影像 — 联影医疗 (688271.SH)

市场逻辑: 国产唯一全产品线(CT/MR/PET/XR/RT)高端医学影像设备企业,正面对国际四大巨头的存量市场国产替代。

投资逻辑: 5T MR / 全身 PET/CT / uMI 系列等高端产品突破 + 海外持续放量 + 上海国资 16.38% 背书。

主要风险: 2024 业绩六年来首降(营收 -9.73% / 净利 -36.08%)+ 经营现金流转负 + 存货 +41.99% + 估值 PE 81 倍偏高。

③ 心血管 — 乐普 / 微创 (双雄)

市场逻辑: 中国心血管疾病患者基数大,冠脉支架集采已完成,结构性心脏病/外周介入/TAVR/创新药是后续增长点。

乐普投资逻辑: 二代蒲绯接棒 + 创新药 GLP-1 MWN101 临床 II 期 + 皮肤科注射剂 + 创新管线丰富。

微创投资逻辑: 出海 +85% / 手术机器人 0.36 亿 (+146%) / 骨科 EBITDA 转正 / EBITDA 由亏转盈 / 12 大业务整合。

主要风险: 集采全面覆盖 + 商誉 + 转型阵痛 + 港股估值折价(微创)。

④ 骨科 — 威高骨科 / 大博 (集采出清)

市场逻辑: 2021-2022 集采腰斩后,2024 V 型反转。"以量补价" + 关节续标涨价 + 运动医学增量 + 国产替代加速。

威高骨科投资逻辑: 净利 +97.5% / 关节续标 +46% / 运动医学 +400% / 母公司威高股份支持。

大博投资逻辑: 净利 +505% (行业最佳) / 微创外科 +26.5% / 海外 60+ 国 + 累计回购 2.5 亿 / 高 ROIC 16.27%。

主要风险: 估值 PE 71 倍偏高 + 应收账款 + 集采续约 + 多元化执行。

⑤ IVD — 新产业 / 安图 (化学发光双雄)

市场逻辑: 化学发光免疫诊断是 IVD 最大细分赛道,2022 规模 400 亿+。罗雅贝西占比 70%+,国产替代空间广阔。集采已在地方试点。

新产业投资逻辑: 海外 +27.6% / 海外占比 37% / 出口 155+ 国 / 1,000T/H X10 全球领先 / 72% 高毛利。

安图投资逻辑: 海外 +36.6% / 5 大产品线协同 / 16.37% 研发费率(全行业领先) / 测序仪新业务。

主要风险: 集采全面覆盖 + 国内增速回落 + 海外汇率 + 安图 2025Q1 继续承压。

⑥ 眼科 — 欧普康视 / 爱博 (消费医疗)

市场逻辑: 近视防控 + 屈光手术 + 白内障手术。OK 镜受消费疲软 + 减离焦框架镜分流影响,人工晶状体受集采影响。但创新产品(硅水凝胶/有晶体眼 ICL/焦深延长型)打开新空间。

欧普康视投资逻辑: OK 镜龙头"梦戴维" / 巩膜镜获批 / 470+ 自营视光终端 / 阿托品滴眼液临床。

爱博投资逻辑: 三大业务协同 / 隐形眼镜扭亏为盈 / 硅水凝胶国产化(国内占比仅 10% vs 全球 70%) / 创新晶体持续获批。

主要风险: 消费降级 + OK 镜需求疲软 + 集采 + 销售费用刚性。
